# Pioneer demo video — handoff for Awaiz

Everything needed to run, rebuild, and extend the Pioneer motion video lives in this repo. The finished render is attached to the v1 release (`pioneer-demo.mp4`, 75.9 s, 1920×1080 @ 30 fps, H.264 + AAC).

## TL;DR

```bash
npm install                        # ffmpeg + ffprobe installer deps only
python tools/logo_svg.py           # only if you change the logo (needs fontTools + brotli)
node tools/durations.mjs           # scan assets/vo/ → meta.json (only after re-voicing)
node tools/build.mjs               # regenerates index.html + assets/mix/*.wav
node tools/hf.mjs check            # lint + runtime + layout + motion + contrast (all must pass)
node tools/hf.mjs render           # → renders/pioneer-demo.mp4 (~3 min on a GPU machine)
```

`index.html` is **generated** — never edit it by hand. Edit `tools/build.mjs` (timings, cues, captions) and/or `engines/*` (visuals), then rebuild.

## The animation engines (engines/)

All visuals are 1920×1080 canvases painted **deterministically from the seeked frame time** — no clocks, no `requestAnimationFrame` state, no `Math.random` (all randomness is `PE.hash`-seeded). `engines/runtime.js` listens for HyperFrames `hf-seek` and renders exactly that time.

| File | Engine | In the video | Source |
| --- | --- | --- | --- |
| `core.js` | shared utils | everywhere | ink-box measure, pen layout, table interpolation, hash, grain |
| `wild.js` | WildType | "intelligence" types → warps → collapses | user's motion spec |
| `shutter.js` | ShutterType | "Cities still break" tear + ground flood | user's motion spec |
| `conveyor.js` | CheckerConveyor | brand card, city/leak/crew/fixed shots, agents row | user's motion spec; scenes are canvases, so real screenshots ride it |
| `warp.js` | WarpType | six agent sentences | user's motion spec (wave/stair/gather/turn/fold/sort cuts) |
| `lights.js` | AI Lights | valves/progress/terminal under rim glow | rebuilt on canvas from the AI Lights React/CSS spec |
| `stamp.js` | StampType | limits, ask-why, 12,400, AED 5.94M | user's motion spec |
| `flip.js` | FlipType | Pioneer → Watches → Decides → Repairs → Pioneer | tables generated by the FlipType rules (seeded) |
| `metal.js` | MetalLogo (WebGL2) | liquid-metal logo: brand card + end card | Paper Shaders `liquidMetal` (Apache-2.0) + its vertex shader, taken unmodified from `metal-fx@2.0.11` (MIT, Jakub Antalik). Keep the header credits. |

### Reusable components worth stealing

- `PE.MetalLogo` — any rasterized image/SVG → liquid metal via Paper's shader in image mode. The hard part is the **shape preprocess** (`processShape`): Poisson solve at half-res → per-stroke normalized dome → R = edge (1 at outline, 0 at spine), G = coverage. Presets in `MetalLogo.PRESETS` (silver/chromatic); tuned params live in `METAL_PARAMS` in runtime.js.
- `PE.scene` helpers (conveyor.js): checker background, grid cells, image cover-crop, framed cards, honest-label tags.
- `PE.Conveyor` — whip transitions row-by-row between pre-painted frames; `pulses` drive scene changes (brand panel is live-painted each frame before the blit, see `paintBrand` in runtime.js).
- Caption overlays: DOM in `index.html` (build.mjs `cap()`), styled inline.
- `tools/logo_svg.py` — font → real SVG outlines: instances Instrument Sans at `wght 500`, applies GPOS PairPos kerning (formats 1+2), emits mark+wordmark lockup as `currentColor` paths.
- `tools/frames.mjs` — headless frame QA without HyperFrames (mini CDP harness + contact sheets via ffmpeg).

## How the build composes the film (`tools/build.mjs`)

1. Reads `script.json` + `assets/vo/meta.json` → per-segment starts/lengths.
2. Sync beats: WarpType cuts on agent-name word onsets; conveyor pulses lead each narration beat; FlipType lands ~0.3 s after "Pioneer".
3. Sound cues: Bencho-derived WAVs in `assets/sfx/` (regenerate: `tools/sfx.mjs`), placed per segment, ~9 dB under voice.
4. Audio pre-mix via local FFmpeg 7.1.1 → `assets/mix/voice.wav` (vol 2.8 + `acompressor` 2.5:1 + `alimiter` at −1 dBFS) and `sfx.wav`. Output measures ≈ −15 LUFS, −1.2 dBFS.
5. Emits `index.html`: one `.seg` canvas per segment (own track + `data-layout-allow-overflow`), 2 audio tracks, caption divs, one paused GSAP timeline, `#pioneer-config` JSON element.

## HyperFrames gotchas (these cost real time — don't relearn them)

- **HyperFrames scopes `window` for inline scripts** — pass data to external scripts via a DOM element (`#pioneer-config`), never a global.
- One root `data-composition-id`, explicit `data-duration`, exactly one paused GSAP timeline on `window.__timelines`. Every timed element needs `data-start` + `class="clip"`.
- Always run `tools/hf.mjs` (not bare `hyperframes`) — it pins 0.8.86, prefers `tools/ffmpeg/` (7.1.1; old FFmpeg lacks `adelay=all`), kills telemetry.
- `tools/ffmpeg/` is git-ignored: unzip `ffmpeg-7.1.1-essentials_build` there, or rely on `@ffprobe-installer`/`@ffmpeg-installer` fallback.
- Low-memory box: render with `--low-memory-mode --quality looks` (already in `npm run render`); GPU rendering on this machine is ANGLE/D3D11 and fine.
- `tools/frames.mjs` server needs real MIME types — add `'.svg': 'image/svg+xml'` if you copy it.
- WebGL path works under HyperFrames screenshot capture because `MetalLogo.render()` draws synchronously per seek with `preserveDrawingBuffer: true`.
