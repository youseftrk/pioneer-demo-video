# Pioneer demo video (HyperFrames)

~76-second demo of Pioneer, opening "In the age of super intelligence…". Real Abu Dhabi twin, six AI agents, your limits, "ask them why", outcome, liquid-metal logo end card. The same liquid metal also fills the brand panel in the conveyor.

Output: `renders/pioneer-demo.mp4` (1920×1080, 30 fps, H.264 + AAC).

## Rebuild

```bash
npm install
npm run voice:fish   # Fish Audio, model s2.1-pro-free, voice id from FISH_VOICE_ID in .env.local
npm run video        # real voice durations → index.html → render
```

Scene lengths, the conveyor pulses, the WarpType cuts (each lands on the narrator saying the agent's name) and the Bencho cues are all computed from the real voice clips, so changing a line re-times everything.

## Motion: Arlan vault engines (engines/)

Each engine is the vault component ported to a seek-driven canvas renderer: HyperFrames fires `hf-seek` with the frame time, and `engines/runtime.js` draws exactly that time. No clocks, no `requestAnimationFrame`, no unseeded random.

| Segment | Engine | What it does here |
| --- | --- | --- |
| Hook | `wild.js` WildType | "intelligence" types in, goes wild through the 9×4 warp mesh with an orange registration slip, collapses home, un-types |
| Break | `shutter.js` ShutterType | "Cities still break" tears in through the rolling shutter; the "under ground" stack scrolls; the ground floods blue |
| Product | `conveyor.js` CheckerConveyor | Rows whip in Pioneer, then real app shots (city, pipes, leak) and the six agents |
| Agents | `warp.js` WarpType | Six sentences: Watch hears trouble, Diagnose finds causes, Plan weighs options, Patch turns valves, Dispatch sends crews, Verify checks work |
| Acting | `lights.js` AI Lights | One body morphs between agent surfaces (steps, progress, terminal) under the rainbow rim pulse |
| Control / outcome | `stamp.js` StampType | Lines on bars hop in and stamp their trail; worlds flood into each other |
| Crew / fixed | `conveyor.js` | Crew drive shot, then the fixed city |
| End | `flip.js` FlipType | Pioneer → Watches → Decides → Repairs → Pioneer |
| Logo showcase | `metal.js` (Paper `liquidMetal`) | The Pioneer SVG in liquid chrome on black, pour-in reveal, tagline flips in |

The logo is a real SVG (`assets/brand/pioneer-logo.svg`, generated by `tools/logo_svg.py`: mark + "Pioneer" outlined from Instrument Sans 500 with GPOS kerning). `metal.js` runs Paper Shaders' liquidMetal fragment shader (Apache-2.0, same material as the app's `metal-fx` Approve button, silver preset) in image mode on the logo's Poisson edge field, one draw per seeked frame.

FlipType's per-letter tables are generated for any words by the vault's rules (seeded). The other engines keep the vault's tables verbatim.

## Tools

- `tools/build.mjs` — beat sheet from the voice, Bencho cues, audio pre-mix (voice compressed and limited at −1 dBFS), writes `index.html`.
- `tools/frames.mjs` — headless check without HyperFrames: renders chosen times through `window.__pe` and writes a contact sheet to `snapshots/engines/`.
- `tools/logo_svg.py` — builds `assets/brand/pioneer-logo.svg` / `pioneer-mark.svg` (needs Python + fontTools + brotli).
- `tools/tts.mjs` — Fish voice per line (`[pause]`/`[emphasis]` cues are S2.1 bracket tags; captions strip them).
- `tools/sfx.mjs` — Bencho sounds rendered to WAV from their synth table.
- `tools/hf.mjs` — runs HyperFrames 0.8.86 with the project-local FFmpeg 7.1.1 (`tools/ffmpeg`, git-ignored).

## Notes

- Little free memory on this machine: renders use `--low-memory-mode` (one worker, screenshot capture) and `--quality looks` (CRF 16).
- HyperFrames scopes `window` for inline scripts, so the engine config is passed as a JSON element (`#pioneer-config`), not a global.
- Screens come from the twin (`qoder-hackathon`). Streets and buildings are real (OpenStreetMap); the pipes, leak, sensors, crews and money figures are a demo scenario, and the labels say so.
- `.env.local` holds the Fish Audio key and is git-ignored.
